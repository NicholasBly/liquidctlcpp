# liquidctlcpp
Ultra lightweight NZXT CAM replacement in c++

Utilizes drivers from liquidctl (converted to c++)

I got fed up with NZXT CAM using 3-5% of my CPU while idling doing nothing. This replacement uses 8-12MB of RAM and 0% CPU usage while idle.

Features:

NZXT Smart Device
LED controls + effects
E Series PSU support

I can add additional support for more NZXT devices, just let me know. I built this for my system so it's pretty much all I need to replace NZXT CAM.
